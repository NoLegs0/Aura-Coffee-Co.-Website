# ☕ Aura Coffee Co. - Website

Landing page responsiva desenvolvida para uma cafeteria artesanal, com foco em experiência do utilizador, design moderno e interatividade.

## 🚀 Funcionalidades
* **Menu Responsivo:** Animação personalizada no menu hambúrguer para dispositivos móveis.
* **Seleção Dinâmica:** Clique nos cartões de produtos com preenchimento automático do formulário de encomenda via JavaScript.
* **Design Moderno & Responsivo:** Layout adaptado para telemóveis, tablets e computadores.
* **Navegação Fluida:** Scroll suave entre as secções da página.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Animações, transições e layout responsivo.
* **JavaScript (ES6+):** Manipulação do DOM e lógica de interatividade.
